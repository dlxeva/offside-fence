# Press kit

> **This is a press kit for a concept demonstrator that is not a real product.** It is published so that any reporter, blogger, or curious viewer who arrives at this repository has a single page that answers the questions a press contact would normally be asked to answer. There is no press team. There is no on-call spokesperson. This file is the entire press operation.

## 1. Headline description

> **OffsideFence is a concept demonstrator for a forward-facing wearable that uses real-time computer vision to detect offside positions and deliver haptic feedback at the moment a forward strays beyond the last defender. The concept is built on top of Roboflow Sports, an open-source pitch-perception pipeline. OffsideFence is not a product, not a startup, not affiliated with Roboflow, and not for sale.**

## 2. Boilerplate (50 words)

OffsideFence is a single-shot concept demonstrator created as part of a content project exploring the boundary between what computer vision can already do for football and what should or shouldn't be strapped to a player's body. It is fictional. It is not a product. It is engineered to look real because that is the deliverable.

## 3. Boilerplate (100 words)

OffsideFence is a single-shot concept demonstrator for a forward-facing wearable that uses real-time computer vision to detect offside positions and deliver haptic tactical correction the instant a forward strays beyond the last defender. The pitch-perception layer is built on top of Roboflow Sports, an open-source computer-vision pipeline for football. OffsideFence is not a product. It is not a startup. The "whether it is real" is the deliverable.

## 7. Talking points (for editors who want a quick framing)

- OffsideFence is **fictional**. Lead with that.
- The engineering register is **real**. Roboflow Sports is open source. The latency math is plausible.
- The deliverable of the content project is **the moment of doubt** — a viewer pauses, checks whether this is real, and confirms with the reader next to them that yes, this looks real.
- The **Inzaghi Legacy** mode is the position the concept takes. It is the most interesting thing in the artifact. If you only have space for one paragraph about the project, make it about Inzaghi Legacy.
- The concept is **not a critique of VAR**. It is a fictional hardware layer that invents a problem VAR doesn't have. Don't frame it as a VAR successor or VAR replacement.
- The author is **a single individual**, not a startup, not a research lab. The project is a content artifact, not a research artifact.
